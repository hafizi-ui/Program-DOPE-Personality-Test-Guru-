# Program DOPE Personality Test (Guru)

Slaid interaktif bagi Program DOPE Personality Test untuk guru, anjuran Jabatan Perniagaan, KPTM Kuantan.

**Fasilitator:** Ahmad Hafizi bin Ahmad Giran, Sharifah Fatimah Khairulnisha binti Syd Noh, Faridah binti Ishak dan Lukman Hakim bin Mat Nasir.

## Cara menggunakan

Buka `index.html` dalam mana-mana pelayar web (tidak memerlukan internet), atau layari versi GitHub Pages.

| Kekunci | Fungsi |
|---|---|
| ← / → atau Space | Slaid sebelum / seterusnya |
| F | Skrin penuh |
| N | Papar nota penceramah |

## Kandungan

1. Pembukaan dan Ceramah Pengenalan: aktiviti suai kenal, pengenalan DOPE, ketepatan ujian, kepentingan kepada guru dan mini cabaran.
2. Aktiviti DP Personality Game Board: pengenalan papan permainan, cara bermain, pemasa dan papan skor kumpulan.
3. Ceramah Susulan dan Refleksi: keputusan personaliti, sesi refleksi dan penutup.

## Fail

- `index.html`: slaid interaktif (satu fail, semua ikon terbenam).
- `Program_DOPE_Guru.pptx`: slaid PowerPoint asal.

> Nota: sahkan sumber bagi angka 17K+, 90%, 78% dan 82% sebelum pembentangan.
